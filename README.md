# React Shopping Cart

## Requirements
Node.js LTS and npm.

## Run
```bash
npm install
npm run dev
```
Open the local URL shown by Vite (usually http://localhost:5173).

## Steps
1. Open this folder in VS Code.
2. Open terminal in this folder and run `npm install`.
3. Run `npm run dev`.
4. Search products and filter by category.
5. Add the same product more than once; verify quantity increases.
6. Increase/decrease quantities, remove items and verify total changes.
7. Run `npm run build` to check production compilation.

## Concepts
Components, props, `useState`, `useMemo`, event handlers, list rendering, conditional rendering and responsive CSS.

## Limitation
Products are sample data held in the React source. Cart state resets on refresh. Checkout is a demo and does not process payment.
